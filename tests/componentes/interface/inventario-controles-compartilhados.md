# Inventário de controles compartilhados

Base: `3161b5b`; busca em `src/components/ui` por `controle` e `bg-secondary`, seguida de inspeção dos elementos e seus estados. Esta é uma auditoria estática de classificação, não uma afirmação de cobertura visual de todas as telas consumidoras.

| Componente                                                                        | Decisão                                                                                                                                                                                              |
| --------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `seletor-ano`                                                                     | Adaptados somente o gatilho e as setas de bloco; células de ano atual e selecionado mantêm sua semântica.                                                                                            |
| `seletor-horario`                                                                 | Adaptado somente o gatilho; opções, seleção e ações discretas não são alteradas.                                                                                                                     |
| `seletor-periodo`                                                                 | Adaptados somente o gatilho e setas do popover, inclusive fora das navegações de data já tratadas; dias/meses atuais, selecionados, resumo e ações discretas não são alterados.                      |
| `painel-acoes`                                                                    | Já usa `Button` secundário, que recebe o tratamento anterior e preserva `aria-pressed`; sem mudança própria.                                                                                         |
| `button` / `button.module.css`                                                    | Já coberto pelo tratamento anterior; fora do escopo de edição.                                                                                                                                       |
| `input`, `selecionar`, `selecionar-buscavel`, `barra-busca` e `campos.module.css` | Campos já tratados em trabalho anterior; fora do escopo de edição.                                                                                                                                   |
| `abas-deslizantes`                                                                | `bg-secondary/60` está no trilho do tablist, não em um botão neutro; o trilho agrupa as abas e serve de contexto para o indicador selecionado. Não transformar abas discretas em botões contornados. |
| `secao-recolhivel`                                                                | `.controle` está no fundo decorativo do ícone, não no gatilho; a seção já tem superfície/limite e variante de perigo.                                                                                |
| `tela-estado`                                                                     | `bg-secondary` é cor semântica do ícone; `.controle` é legenda não interativa.                                                                                                                       |
| `selo`                                                                            | Badge informativo com variantes semânticas, não controle.                                                                                                                                            |
| `circulo-contagem`                                                                | Contadores informativos, incluindo tom de saída, não controles.                                                                                                                                      |

## Evidência e limites

Os testes Chromium montam componentes reais com CSS da aplicação e sem banco. Antes da alteração, os três testes de ano/horário e o teste de período falharam por encontrar o fundo secundário em vez de transparente; depois passaram. Exercitam 320, 390 e 1280 px nos dois temas, teclado, seleção, bloqueio, tamanho e contraste dos gatilhos, além de cores forçadas para o seletor de ano. O tema escuro de ano/horário é comparado com as cores calculadas antes da alteração; o CSS novo é restrito ao tema claro. As capturas são de fixtures isoladas, não de todas as páginas da aplicação. O modo dia do seletor de período e todos os consumidores finais não foram revisados visualmente de modo exaustivo. A suíte integrada de navegação inteira excedeu 180 s neste host; o caso específico atualizado foi executado isoladamente.
